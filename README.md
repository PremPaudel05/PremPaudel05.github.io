# Prem Paudel — Portfolio

Personal portfolio built with Next.js, TypeScript, Tailwind CSS, and shadcn-style reusable UI components.

Live site: https://prempaudel05.github.io/

## Contact form

The static GitHub Pages site sends form submissions through [FormSubmit](https://formsubmit.co/) to `Prempaudel5b@gmail.com`. The form collects first name, last name, reply email, and message. FormSubmit handles verification and the submission confirmation screen; the site does not store messages or expose an email API key.

Before relying on delivery, submit the live form once and approve the activation email sent by FormSubmit to the recipient inbox (check Spam if needed). After activation, submit a test message and verify receipt. Keep the provider's default CAPTCHA enabled. The direct email link remains available independently of the form.
